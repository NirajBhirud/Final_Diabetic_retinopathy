The Problem

Blindness That Can Be Prevented

Diabetic Retinopathy is a complication of diabetes that damages blood vessels in the retina. It is one of the leading causes of blindness worldwide — yet with early detection, over 90% of vision loss is preventable.

Traditional screening relies on trained ophthalmologists manually examining fundus images — a process that is slow, costly, and inaccessible in many regions. This project automates that process using a deep Convolutional Neural Network trained on the Kaggle Diabetic Retinopathy dataset.

Classification

Diabetic Retinopathy Severity Grades

The model classifies retinal images into 5 clinically-defined grades, enabling precise triage and clinical decision support.

👁️
Grade 0
No DR
No signs of diabetic retinopathy detected. Healthy retinal vasculature.
🔵
Grade 1
Mild
Microaneurysms only. Earliest clinical sign of DR; typically no visual symptoms.
🟡
Grade 2
Moderate
More than microaneurysms but less than severe NPDR. Possible exudates and haemorrhages.
🟠
Grade 3
Severe
Significant vessel damage — haemorrhages in 4 quadrants. High risk of progression.
🔴
Grade 4
Proliferative DR
Neovascularisation present. Highest severity — risk of vitreous haemorrhage and blindness.
Workflow

How the System Works

From raw fundus image to classified severity grade in four key stages.

1. Upload Retina Image

Clinician uploads a fundus photograph. The system accepts JPEG/PNG images of any resolution.

2. Preprocessing

Image is resized, normalised, and optionally augmented to match the CNN input requirements.

3. CNN Inference

The trained CNN processes the image via TensorFlow Serving REST API and outputs class probabilities.

4. Grade Classification

The system outputs the predicted DR grade (0–4) with confidence scores for clinical review.

Trained on the Kaggle Diabetic Retinopathy 224×224 (2019) dataset with 5 classes.

Jupyter Notebooks

Exploratory data analysis and model experimentation in interactive notebooks.

REST API

TF Serving exposes a JSON REST endpoint for real-time image inference requests.
